# LJT-Homepage

Personal academic homepage of **Junteng Liu**.

- Website: https://chaosselead39.github.io/LJT-Homepage/
- Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template, forked from [academicpages/academicpages.github.io](https://github.com/academicpages/academicpages.github.io).

## Pages

- **About** (`_pages/about.md`): personal details, education and academic background, honors and awards, research experience, publications, skills and research interests, and contact information.
- **Publications** (`_pages/publications.html`, with the list generated from `_publications/`): all publications, which are also listed in the Publications section of the About page.
